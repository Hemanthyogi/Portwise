# PORTWISE — Frontend Application
React 18 + TypeScript + Vite + Tailwind CSS + Axios + Recharts + Lucide Icons

## Features
- **Enterprise Naval Aesthetic**: Professional Navy blue, White, Port blue, and Teal brand theme.
- **Role-Based Views**: Dynamic route guards and navigation scoping according to user authority.
- **Telemetry Visualizations**: Recharts integration for vessel distribution, cargo throughput, and berth utilization.
- **Cargo Chain-of-Custody Timeline**: Visual vertical step-progression tracking with operator accountability.
- **One-Click Demo Credentials**: Instant role switching for evaluation and testing.

## Commands
```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build production bundle
npm run build
```
